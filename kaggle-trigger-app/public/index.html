Kaggle Authentication

How to get your Kaggle API key:

  1. Go to Kaggle.com and log in.
  2. Go to your profile (top right) -> Settings.
  3. Scroll to the API section and click Create New Token.
  4. Open the downloaded kaggle.json to find your username and key.
✓ All credentials saved locally in your browser!
